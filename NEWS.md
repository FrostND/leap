# leap (development version)

## New features

- Initial development of tools for identifying and representing repeated treatment episodes in longitudinal clinical data.
- Added functions for describing episode structure and patterns of treatment utilization.
- Added visualization tools for examining treatment trajectories within and across episodes.
- Added support for longitudinal mixed-effects and slopes-as-outcomes models.
- Added support for Bayesian multilevel models of repeated treatment episodes.

## Documentation

- Added a **Get Started** guide introducing the core `leap` workflow.
- Added articles covering longitudinal data, treatment episode identification, visualization, and statistical modeling.
- Added simulated psychotherapy data for demonstrating common longitudinal treatment patterns.

The `leap` package is under active development. Function names, arguments, and model specifications may change in future releases.
